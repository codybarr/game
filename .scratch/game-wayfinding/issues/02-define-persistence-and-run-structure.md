# Define Persistence and Run Structure

Type: grilling
Status: resolved

## Question

Should the game use one wholly persistent character and world, discrete roguelite runs with meta-progression, or a hybrid? If hybrid, what is lost on failure, what persists, and why does that loop enhance a loot-and-min-max RPG rather than dilute it?

## Answer

Use one persistent character and world; do not use roguelite run resets. On defeat, return the player to the home region and reset only temporary expedition progress. Permanent XP, use-based skill gains, gear, home unlocks, and banked loot remain. This keeps long-term loot and build optimization intact while making individual expeditions meaningfully risky.
